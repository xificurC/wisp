## What changed

**`wisp/wisp`**

`body_of_anthropic` now ends its thinking branch with:

```python
    thinking = world.get("thinking")
    if thinking:
        body["thinking"] = {"type": "adaptive"}
        body["output_config"] = {"effort": thinking}
    return body
```

`DEFAULT_THINKING_BUDGET` and `ANTHROPIC_MIN_BUDGET` leave the constant block. `DEFAULT_MAX_TOKENS` and `WISP_LLM_MAX_TOKENS` stay, so `max_tokens` keeps its cap. The docstring states that adaptive thinking moves the depth choice to the model, and that only fields the messages API names are ever set.

I confirmed both fields on `https://platform.claude.com/docs/en/api/messages.md`, read today. `OutputConfig.effort` accepts `low`, `medium`, `high`, `xhigh`, and `max`. `ThinkingConfigAdaptive` takes `type: "adaptive"` plus an optional `display`. The page names `{"type": "enabled"}` as manual extended thinking and ties `budget_tokens` to that mode alone.
