Goal: make `wisp` run on the OpenCode Go subscription, and show the recipe for `deepseek-v4.1-flash`.

**One sentence:** wisp now talks to `https://opencode.ai/zen/go/v1` through a new `WISP_LLM_HEADERS` env variable, and one console setting stands between you and DeepSeek V4.1 Flash.

**Four sentences:** OpenCode Go is a subscription behind its own base URL, not the plain Zen endpoint; the Zen paths answer `Insufficient account funds` for this key. The Go endpoint demands a stable `x-opencode-session` header per conversation and rejects library user agents with `403 error code 1010`. wisp gained `WISP_LLM_HEADERS` (one JSON object, `{session}` expands to the session name) and now sends `User-Agent: wisp`. DeepSeek V4.1 Flash is region-gated to Global, so I verified the whole path with `glm-5.3-flash` on identical wiring.

## The recipe

```shell
export WISP_LLM_URL=https://opencode.ai/zen/go
export WISP_LLM_API_KEY="$OPENCODE_API_KEY"
export WISP_LLM_API=openai-chat
export WISP_LLM_HEADERS='{"x-opencode-session":"{session}"}'
export WISP_SESSIONS_ROOT=$PWD/wisp-sessions

DIR=$(wisp new -m deepseek-v4.1-flash -t high)
wisp run -d "$DIR" <<<"Use the bash tool to print the current directory." | wisp render-live
wisp response -d "$DIR"
wisp usage -d "$DIR"
```

`WISP_LLM_URL` takes the base URL without `/v1`. Your key never leaves the environment; wisp reads `WISP_LLM_API_KEY`.

## What I changed in wisp

- `wisp/wisp`: new `extra_headers_of` parses `WISP_LLM_HEADERS`, fails on a non-object, and substitutes `{session}` with the session dir's base name. `auth_headers_of` merges those extras last, so an endpoint with another auth scheme can replace the default header. `USER_AGENT = "wisp"` now rides every request.
- `wisp/tests/test_providers.py`: four new cases (extras land, extras win over auth, bad JSON exits 1, client names itself). `pytest wisp/tests tests -q` gives 148 passed; every `tests/test_wisp_*.sh` passes.
- `md/notes/opencode-go.md`: the full recipe, the two refusal texts, the model list call, the modelcfg entry, the region gate, and the free-tier distinction. `md/notes/providers.md` gains an "Extra headers" section pointing at the note.

## Two facts that cost me time

- The required header is easy to miss: without it you get `MissingSessionID`, and wisp could not send a custom header before this change.
- The `-free` model ids belong to the OpenCode client, not to Go. A key answers `FreeUsageLimitError` on them.

## The DeepSeek blocker

`deepseek-v4.1-flash` answers:

```
This Go model is hosted outside Europe and the United States. Select Global at
https://opencode.ai/console/<your-org>/settings/privacy#regions to use it.
```

Set Global under Settings › Privacy › Regions in the OpenCode console as workspace owner or admin. No local change opens that gate. Until then, swap `-m glm-5.3-flash`; I ran a text turn and a full tool round on it and both exit 0.

## Price and context window

Go answers 404 on `/v1/model/info`, so `wisp usage` prints `<noprice> <nocontext>` and `--context-guard 70%` fails. Write the entry by hand:

```shell
echo '{"deepseek-v4.1-flash": {"context": 1000000, "input": 0.3, "output": 1.2, "cacheRead": 0.006, "cacheWrite": 0}}' \
  > "$DIR/wisp.modelcfg"
```

A failed refresh writes nothing, so the file survives. That turned a guard run into `in 1.5k out 20 $0.000 524/1.0M 0.1%`. Treat the dollars as list-price estimates, because Go bills against a monthly allowance.
