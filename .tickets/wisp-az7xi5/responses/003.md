**Goal of this turn:** make harbor usable without a global install, build the `bench/` benchmark home in the wisp repo, and prepare validated dry-run and real-run commands — without executing any benchmark.

**TLDR:** `bench/` now holds a hardened wisp adapter, a `bin/harbor` launcher that fixes "harbor not on PATH" by reusing the curated-terminal-benchmark venv (harbor 0.24.0), a fallback installer, an aggregator, and a README of commands. Everything except actual trial runs was validated, including a `--print-config` dry-run and the full 89-task dataset prefetch.

## What was built — `/home/pnagyux/code/wisp/bench/`

| File | Role |
|---|---|
| `wisp_harbor.py` | Harbor agent adapter (`wisp_harbor:Wisp`). Moved from `experiments/bench/`, which no longer exists. |
| `bin/harbor` | Launcher shim. Sets `PYTHONPATH=bench/` so the adapter resolves, then execs `bench/.venv/bin/harbor` if installed, else the curated venv (harbor 0.24.0). |
| `install.sh` | Fallback installer: fresh venv with `harbor==0.24.0`. Prepared, not run — the curated venv serves. |
| `aggregate.py` | Jobs-dir aggregation: pass rate, mean reward, in/cache/out tokens, cost, seconds, plus per-task rows. |
| `README.md` | All commands below, plus env requirements and notes. |
| `.gitignore` | Keeps `jobs/` and `.venv/` out of a future commit. |

Adapter hardening (ticket Gap 3): `install()` apt-installs python3/git/ca-certificates in the task image and uploads the host CA bundle and price table; `run()` sets `SSL_CERT_FILE` and `WISP_LLM_MODEL_INFO_FILE`. I also fixed a wart from the probe version: the model-table env var was set unconditionally even when no table was uploaded; now it is set only when the host file exists. The redactor was dropped per your instruction. Nothing is committed.

## Commands

Dry-run (resolve and exit, no trials):

```bash
bench/bin/harbor run -d terminal-bench@2.0 -a wisp_harbor:Wisp \
    -m MODEL -e podman -l 20 -n 4 -k 1 -y \
    -o bench/jobs/tb2-first --print-config
```

Smoke test (one trivial task, ~1 min) and install-only probe are also in the README.

First real pass — 20 of 89 tasks, 1 attempt, 4 concurrent:

```bash
bench/bin/harbor run -d terminal-bench@2.0 -a wisp_harbor:Wisp \
    -m MODEL -e podman -l 20 -n 4 -k 1 -y \
    -o bench/jobs/tb2-first
```

Full pass — all 89 tasks, 3 attempts for a pass-rate interval:

```bash
bench/bin/harbor run -d terminal-bench@2.0 -a wisp_harbor:Wisp \
    -m MODEL -e podman -n 4 -k 3 -y \
    -o bench/jobs/tb2-full
```

Aggregate:

```bash
python3 bench/aggregate.py bench/jobs/tb2-first
```

The environment already exports `WISP_LLM_URL`, `WISP_LLM_API_KEY`, and `WISP_LLM_MODEL_INFO_FILE`, which the adapter passes through; no extra env setup is needed.
