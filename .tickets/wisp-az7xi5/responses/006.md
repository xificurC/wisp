Goal of this turn: find a benchmark loop that finishes in 1–5 minutes, per the steer to use the fastest Terminal-Bench 4.0 tasks.

**TLDR:** The public Terminal-Bench leaderboard publishes no per-task timings, so I ranked tasks from published per-trial records and capped agent execution at 101 s; the resulting two-task loop finishes in 3m 09s for $0.00092.

**Why the 45-minute run stalled.** Terminal-Bench 2.0 gives each task an agent timeout of 900–3600 s. wisp's `DEFAULT_WALLCLOCK` is 24 h (`wisp/wisp` line 399), so wisp never stops itself. Harbor killed two trials at its own timeout: the code-golf task at 900 s and `llm-inference-batching-scheduler` at 1800 s. Only `hello-world` has a 120 s timeout in all of 2.0. `--effort xhigh` added model latency on top: `llm-inference-batching-scheduler` burned 1.39M input tokens in 1800 s.

**What public timing data exists.**
- `tbench.ai/leaderboard` embeds only `avg_trial_duration_sec` per model, 3,500–7,400 s for the top entries.
- The 4.0 dataset publishes `expert_time_estimate_hours` per task, 0.75 h and up.
- `~/code/curated-terminal-benchmark/results/*.json` carries per-trial `started_at` and `finished_at`. That is the only per-task runtime data available.

**Fastest 4.0 tasks, median trial time over 9 runs each:** `session-window-debug` 419 s, `bun-sourcemap-leak` 421 s, `wal-recovery-ordering` 565 s, `mvcc-lsm-compaction` 593 s, `music-harmony` 611 s. Even the fastest task needs about 4 minutes uncapped, so a 1–5 minute loop needs a cap.

**Validated loop, 3m 09s, $0.00092, two trials in parallel:**

```
bench/bin/harbor run \
  -p ~/code/curated-terminal-benchmark/artifacts/datasets/terminal-bench \
  -i session-window-debug -i bun-sourcemap-leak \
  -a wisp_harbor:Wisp -m MODEL -e podman \
  -n 2 -k 1 -y --agent-timeout-multiplier 0.0035 -o bench/jobs/quick4
```

Terminal-Bench 4.0 task timeouts are 28800 s, so multiplier 0.0035 caps agent execution at 101 s. Per-trial phases ran environment 10–14 s, agent setup 25–37 s, agent 101 s, verifier 20–33 s. Job: `bench/jobs/quick4/2026-11-19__10-04-17`.

**Costs of the choice.** Both trials end with `AgentTimeoutError` and reward 0.0, so the loop tests the harness, not the model. Uncapped scoring runs on these two tasks cost 4–7 min each. The adapter installs python3, git, and the CA bundle per trial, which is 25–37 s of the 3 minutes.

**Other levers.**
- `hello-world@1.0` ran in 1m 03s today with reward 1.0. It is the 1-minute smoke for adapter changes.
- Drop `--effort xhigh` for iteration; the flag inflates per-turn latency and token cost.
- `-k 3` on one task gives three parallel attempts in about the same wall time.
