**Goal:** decide how to run wisp against a large, ready dataset without building a benchmark.

**TLDR:** The framework exists. Harbor, already installed in `~/code/curated-terminal-benchmark`, runs 80 registry datasets with a 93-line wisp adapter. Two runs passed today, so the remaining work is one adapter file, not a benchmark.

## The framework exists

`~/code/curated-terminal-benchmark/.venv/bin/harbor` is Harbor 0.24. Harbor is the runner behind Terminal-Bench. Harbor pulls a dataset by name and runs one task per container:

```
harbor run -d terminal-bench@2.0 -a mywisp:Wisp -m MODEL -e podman -l 20 -n 4
```

`-d NAME@VERSION` resolves through the registry, so no download step runs first. `-l N` caps the task count, `-i GLOB` filters task names, `-k N` repeats each task, `-n N` sets concurrency. The registry index is `raw.githubusercontent.com/laude-institute/harbor/main/registry.json` and lists 80 datasets.

## The adapter is one file

`/home/pnagyux/code/wisp/experiments/bench/wisp_harbor.py`, 93 lines, uncommitted. The adapter uploads the single wisp script, runs `wisp new` and `wisp run` on the instruction, and reads `wisp.usage` into the Harbor result. Harbor passes the task instruction and the container, so the adapter holds no task logic.

The second run cost about $0.0016. Model latency was 66 s of the 134 s; tool execution was under 1 s.

## Three container facts, found by trial

1. Task images may lack `python3` and `git`. wisp needs both.
2. `git_root` calls git without a guard. A container without git makes `wisp new` exit 1 with `kind=internal` and a traceback only in `wisp.log`.
3. The LiteLLM certificate chains to the internal `CA-GTICA2K8` root. The public bundle does not verify it; `SSL_CERT_FILE` pointing at the host bundle fixes the failure.

Harbor also passes agent env through `docker compose exec -e`, so the API key lands in `trial.log`. The curated repo already has a `ctb.privacy` redactor for this; the probe adapter has none.

## Recommendation

Run Terminal-Bench 2.0 first, then Pro, then Aider polyglot if cheap volume matters:

```
export PYTHONPATH=/home/pnagyux/code/wisp/experiments/bench
harbor run -d terminal-bench@2.0 -a wisp_harbor:Wisp -m MODEL -e podman -l 20 -n 4 -o runs/tb2
harbor run -d terminal-bench-pro@1.0 ... -l 40
harbor run -d aider-polyglot@1.0 ... -l 100
```

Add the CA bundle and the `git`/`python3` install to the adapter before the first real round. Copy `ctb.privacy` into the adapter before sharing any result.

Reject the bespoke harness from the scout: the registry covers every track except compaction, and task authoring was the expensive part. No registry dataset tests wisp's guard-stop handoff; that experiment still needs a proposed task pair.
