Goal: make `harbor view` show cost and token consumption for wisp bench trials.

TLDR: The adapter never populated `cost_usd` and never wrote an ATIF trajectory, because Harbor skips `populate_context_post_run()` once `run()` fills the `AgentContext`. The adapter now does both in the post-run hook; a backfill script repairs existing jobs.

## Cause

Harbor's `_populate_agent_context()` calls `populate_context_post_run()` only when `agent_result.is_empty()` is true. The old adapter wrote token totals inside `run()`, so the context was never empty. Harbor therefore skipped any post-run work, `result.json` kept `cost_usd: null`, and no `agent/trajectory.json` existed. The viewer reads job and trial table totals from `result.json` and reads per-step token metrics plus total cost from `trajectory.json`; both sources were missing cost.

## Fix

`bench/wisp_harbor.py`:
- Removed context population from `run()`; the in-container `wisp.usage` scrape remains as a fallback only.
- Added `convert_trajectory()`: parses `agent/wisp-sessions/wisp/wisp.jsonl` into ATIF steps, including tool calls and observations, with per-step `prompt_tokens`, `completion_tokens`, `cached_tokens`, and `cost_usd`.
- Added `populate_context_post_run()`: writes `agent/trajectory.json` with `final_metrics`, then copies `cost_usd` and the three token totals onto the `AgentContext`. Harbor backfills `model_usage` from the trajectory.

`bench/backfill.py`: converts transcripts for jobs run before the fix, rewrites each trial `result.json` `agent_result`, and recomputes job-level totals.

## Verification

Fresh run `hello-world@1.0` at `bench/jobs/smoke2/2026-11-18__14-55-05`:
- `result.json`: 3,430 in / 83 out / `cost_usd 9.71e-05`.
- `agent/trajectory.json`: 3 steps, matching `final_metrics`.
- Viewer API: `total_cost_usd 9.71e-05`, trajectory endpoint returns per-step metrics.

Backfilled pre-fix job `bench/jobs/smoke`: trial totals changed from 1,754 in / 135 out / null cost to 3,426 in / 191 out / $0.000156. The viewer API returns the new totals and a 3-step trajectory.

## Display limits

Harbor hides token columns by default on the job page and trial table. Click `Columns` and enable the three token columns. Harbor prints table USD with two decimals, so sub-cent trials read `$0.00`; the trial step list and `bench/aggregate.py` print four decimals.
