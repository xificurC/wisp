## What the answers changed

- **Y5 (the big one).** `--require FIELD:TYPE` declares a result field, and the field name becomes the event verb. `--require passed:bool` makes `--event agent-type:verifier.passed` legal, and `agent-type:foo.count>3` compares an integer. Q36 therefore flips: the outcome domain lives on the rule, not the agent type. I kept one fixed verb on a type subject, `agent-type:T.failed`, because a crashed run otherwise matches no rule.
- **F1.** A cap counts atoms matching an expression against a threshold: `--cap agent-type:verifier.passed<3`. The counter scope has no scope word, so N2 asks for it. Your own example, `agent-type:design-verifier.done<3`, no longer parses under Y5, and I rewrote the example.
- **F2** is answered by Y5. **F3** gains a change check: an output that already has a cell version and comes back byte-identical fails `no_change` after one re-prompt.
- **Y4.** An agent type is a `wisp new -d <space>/agent-types --name verifier -s <persona>` session directory. A run is a `wisp fork` of that directory. No type file format exists in v0.
- **F4.** The engine never calls `wisp steer`. `ember steer` writes `space.steer`, and the engine starts a steward run. W1 leaves the required change set.
- **Y6.** A restart re-declares its `--in` and `--out`; interface inheritance is gone. `--id` is unique per space.
- **Y2.** Negation, `or`, aggregate counts in `--event`, and two multi-subject conjuncts are refused at `rule add` as `not implemented in v0`. Per-rule atom consumption stays, because F1 needs it.
- **F8 and Y8.** No root rule library in v0. Flat authority, with creator, version, and disabling run recorded on every rule row.
- **Y9 and Y13.** Settled means no live run, no pending action, no enabled rule. Park and cancel wait. Durability is a committed log, a two-phase start, and a startup scan that turns a non-terminal run with a free lock into a failed run.
- **Y10 and Y11** were jargon questions, so `rule-language.md` §2.1 and §2.2 now explain injection versus restart, steward concurrency, pending actions, per-type slots, and invisible healing in plain words.

## F7 scout, measured on this host

- Per-run namespaces are unavailable: `unshare -Ur -m` fails `EPERM` on `uid_map`, and `bwrap` fails "setting up uid map: Permission denied". Overlayfs capture, fanotify, and bpftrace are all out for want of privilege.
- A stdlib Python snapshot diff gives the exact set `del.txt -`, `mod.txt ~ +10`, `new.txt +`. Two walks over 200 files cost 16.5 ms.
- `strace -ff -y` gives the operation and the resolved path per pid, with no privilege.
- **Pick:** each run works in `<space>/work/<rid>/`. A directory diff cannot blur under cap 3, because two live runs share no directory. nono stays a sandbox and stops being the recorder.

## Defect found

`wisp new` bakes `<environment>` into the first system record with the absolute `SESSION DIR` (`wisp/wisp` 209-240; a real record confirms it). A verbatim fork makes every run believe it lives in the type directory, so its `-d`, spill path, and session identity are all wrong. W7 now requires the fork to rewrite `SESSION DIR`, `SESSION CREATION TIME`, `MODEL`, and `THINKING`. W11 now requires `-d` to name the parent directory, because your command passes both `-d` and `--name`.
