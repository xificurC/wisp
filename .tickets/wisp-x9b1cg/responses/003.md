## R4: yes, in `wisp`, with one lock

The race has four steps:

1. The writer opens `wisp.steer.inbox` for append.
2. The drain renames the inbox to a consumed name.
3. The writer writes into the renamed file.
4. The drain removes the renamed file.

The line lands in an unlinked inode. The message is lost.

An ember-side lock cannot close the race. `wisp steer` does not take the ember lock. The lock must live in `wisp`, because `wisp` owns both sides.

The fix is one lock file per session dir, `wisp.steer.lock`. The writer holds the lock from open to close. The drain holds the lock for the rename only. The kernel releases the lock on process death. Both waits are 100 ms. The failure branches are explicit: the hearth leaves the delivery in `held`; the drain exits 76 before the first turn; `wisp steer` exits 1.

Evidence: a test harness drove the real `steer_command` and `steer_intake`. Without the lock, one message lost. With the lock, 50 runs, 0 losses. The `wisp` patch is not applied. The patch is a v0 prerequisite.

The drain has a second window. The current `steer_intake` removes the consumed file before the commit. A hard kill in that window loses the drained messages. The fix flushes first, removes second, and drains leftover consumed files only at run start. The inbox line and the digest line carry typed keys (`ember_id`, `ember_wake`). The drain skips a key already in the records. No loss, no duplicate.

## Messaging: no note class

A note waits for the next natural turn. A member may never have a next natural turn. The design removes the note class. Every message gets one of three outcomes:

| Outcome | When | Cost |
|---|---|---|
| soft | the member has a live run | no extra turn |
| hard | no live run, a slot is free | one turn |
| held | no slot, or the model is parked | one turn when a slot frees; TTL is 1 hour |

An expiry row is the only cancel. The sender sees the recipient count and the new-run count before the commit.

## Spawn: no wake

`ember spawn` creates a member, writes `member.joined`, and starts no run. The member is idle. The spawner sends `ember dm <name> "<task>"`. The `dm` is a hard wake and costs one turn. The design removes the `--send` option from `spawn`. `--probe` is an explicit template smoke test, not the default.
