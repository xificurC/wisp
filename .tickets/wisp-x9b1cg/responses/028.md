**Goal of this turn:** answer the two README complaints — the missing agent definitions and `--out` — and land the change the owner asked for.

**TLDR:** `--out` is gone; a run now delivers by its final assistant message, which the engine injects into the next run's briefing. `ember/README.md` gained an Agents section and an Answer section, and the suite passes 141 checks.

## What the owner's proposal settled

N24 settles as (a): drop `--out`. A rule no longer declares a file. Every firing whose trigger names a run carries that run's last assistant text, read from `<run dir>/wisp.jsonl`, into the next briefing as:

```
answer: run r-1a2b3c (worker), the trigger run's final message
  <the message, indented>
```

`--require FIELD:TYPE` stays the typed half of the contract. `no_response` replaces the file-existence gate, and `no_result` is unchanged. A trigger run with no text prints `answer: none (run <rid> (<type>) ended with no final message)` instead of failing the firing.

Two bounds decide the shape. A run cut by a wallclock or a guard keeps whatever text it wrote before its last tool call, so a stopped run still hands something on. A wholly textless turn never reaches the engine: `wisp` fails it with exit 79 (`degenerate`) first, so `no_response` fires on the crash-and-adopt path, where `reconcile` would otherwise mark a field-complete run done with no answer.

## Code, in `ember/ember`

- Removed: `--out`, `OUT_CATEGORIES`, `parse_cells`, `out_cell_ok`, `output_path`, the `no_output`/`no_change` checks, the output half of `finish_success` and `briefing_of`, and the space `resource/` directory.

- `contract_problems` reports `no_response` then `no_result`; `reprompt_text` and `failure_report` carry a fix line for each.
- `ember query run:<id>` prints the answer under `answer:`; `--json` carries it as `answer`.
- `add_rule` refuses `--in .out` with a message naming the default. The `outputs` column stays at `[]`, so an older store reads unchanged, and `row_json` no longer exposes it.
- `run_of_atom` now accepts the briefing's decoded atom dictionaries, which `answer_block` passes.
