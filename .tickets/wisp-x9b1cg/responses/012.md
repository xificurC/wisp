Key content of the document:

- **First principles.** A coordination system is one function: history of finished work → set of next actions. The only design question is where that function lives: the owner's head, inside agents (the old ember), or outside as declared data (the pivot). The settled law survives and sharpens: no model evaluates rules; judgment moves to rule-authorship time. The cost variable the owner pays is how many sequencing decisions are model turns — the rule engine pays zero.
- **Decomposition vs delegation.** Delegation bundles judgment with waiting; the delegating agent stays live and burns a slot and context. Decomposition freezes judgment into rules at split time: N child jobs plus a join rule that wakes one continuation. The engine does the waiting. The price: the join shape is fixed when the split is made.
