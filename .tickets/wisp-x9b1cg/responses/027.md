## The split you named

- `--cap 'count(agent-type:reviewer.approved=false)<4'` counts only the no-go atoms. The value test sits inside the count.
- `--cap 'count(agent-type:reviewer.defects>5)<4'` counts the reviewers who reported more than five defects. That form parses today.

So a value predicate never appears bare in `--cap`, and a count never appears in `--event`.
