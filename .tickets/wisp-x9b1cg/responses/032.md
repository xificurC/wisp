**What landed in `ember/ember` (3144 lines):**

- **State root.** `state_root()` resolves `EMBER_STATE_ROOT`, default `~/.local/state/ember`, mode 0700. It holds `ember.db`, `hearth.sock`, `hearth.pid`, `hearth.log`. `ember hearth start` takes no space; `serve()` binds one socket and writes one pid.
- **One database.** A `spaces` registry table (id, path, paused, created). The space binding in every table (`atoms`, `rules`, `runs`, `consumed`, `joins`, `cells`, `files`, `meta`) is the space's directory path. `atoms.seq` globalizes; run ids stay globally unique; rule ids and cell names become per-space (`PRIMARY KEY (space, id)`, `(space, name, version)`). Every query filters by the binding, so the round-7 cross-space isolation stays physics: a rule id, a cell name, and an agent type name may repeat across spaces.
- **Request routing.** The CLI resolves `--space`/`EMBER_SPACE`; the payload carries the space; `dispatch` resolves it through `ensure_space`, which registers an unknown path. `open_read` checks the registry and refuses an unregistered path with exit 2.
- **Global cap.** `admit` counts `live_runs_all` across every space; `next_pending` picks pending rows round-robin (cursor on the hearth) and skips paused spaces, so a slot freed in one space starts a pending run in another. `reconcile_all` walks the registry at daemon start; `Hearth.poll` takes each run's space from its row.
- **New verbs.** `ember space list`, `ember space pause`/`unpause` (admission holds, rules still fire), `ember space export [-o FILE]` (one space's nine-table control-plane rows as JSON; content stays on disk). A mutating verb with no hearth now answers `the hearth is not running; run ember hearth start` instead of a traceback. Per-space stores from rounds 12-26 are not migrated.
