## Delivery proof

The hearth sends a body block with an opaque key: `<!-- wisp:message key="12a1" -->`.

`wisp send` appends the block to `<session>/wisp.prompt.md` and injects a steered record.

`wisp` writes `wisp_steer_key: "12a1"` on that record in `wisp.jsonl`.

The hearth reads the key and writes `msg.consumed 12a1`.

`wisp` learns the generic word `key`, never the word `ember`.

A run killed before the commit leaves no key, so the hearth redelivers.

`wisp status --json` exposes committed keys, so the hearth does not parse `wisp.jsonl`.

## Review decisions

| Review point | Round-3 decision |
|---|---|
| `ember dm w2 "$(cat plan.md)"` | Bodies only via `-F FILE` or `-F -`; no argv body; missing `-F` exits 2 |
| `--expect reply` | Removed; a reply is `--re MSGID`; no request table |
| `ember probe` and `prompt 812 tok` | Removed; `prompt` was request tokens and `completion` was response tokens; test `llm_route` directly |
| `--job` | `--job FILE`; `-` reads stdin |
| `--lease` | Removed; a member ends by `left`; no eviction |
| `ember await` | Removed; fully async; the reply wakes the requester |
| `--ttl S` | Removed from the CLI; one root policy `message_ttl_s` default 3600 |
| `--id SENDID` | Removed from the CLI; the CLI retries once with an internal request id |
| `--corr C` | Removed from the CLI; `--re MSGID` sets the thread; `log --re MSGID` filters |
| `ember tail` | Removed; the SSE UI streams; `log` reads the past |
| Spawn T/J/R/E | Collapsed to `spawn --agent A --job FILE [--name N]`; agent definition carries type, role, expectations |
| `depth` | Counts generations, not types; Q16 asks whether to keep the third cap |
| `model.default`, `model.fallback` | Removed; agent definition names a type; `llm_route <type>` names model, thinking, fallback |
| Wall clock | Default 600 s; `--wallclock S` per message; a starting run uses the minimum pending value |
| Guard 75 | Distill immediately; no one-time raise; follow the `wispy` recipe |
| One live run per member | One run per member session directory; two members of one type run concurrently |
| Body digest pointer | Digest holds ids and excerpts only; body lives in SQLite; over 2 KB the block is a pointer |
| `wisp send` | Prompt file `<session>/wisp.prompt.md`; append-only Markdown; `<!-- wisp:message -->` blocks; running send watches and steers |
| Wisp tiers | W2/W4/W5/W10/W12 accepted; W1/W3 absorbed by W0; W6 deferred; W7 replaced by fork; W8 dropped; W9 rejected |
| Compaction | No `wisp compact`; distill turn in the stopped session, then a new session with the job and summary |
