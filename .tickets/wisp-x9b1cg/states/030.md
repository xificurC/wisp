- The cap is per-space today: `admit(limit=CAP_DEFAULT)` counts `live_runs(conn)` on one space's `ember.db`, the socket is `<space>/hearth.sock`, and no cross-space state exists, so two hearths give six concurrent runs; a global hearth needs a space registry and one live-run count across the daemon's open connections. (From: `ember/ember` `admit` 1366, `socket_path` 2007, `db_path` 104) (Serves: task N27)
- A spawned run carries no `PDEATHSIG` and no session tie beyond `hearth.track`, so a hearth death orphans the run to init, the run keeps its lock, and `reconcile` adopts it at restart: a global daemon restart costs a pump/poll pause, not lost work. (From: `ember/ember` `spawn_run` 947, `reconcile` 1995) (Serves: task N27)

(From: `ember/ember` `maybe_settle`, `admit`, `live_runs`, `LIVE_STATES`) (Serves: task N25)
