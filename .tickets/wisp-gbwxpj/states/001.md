(From: `./wisp/wisp --help`, `wisp new --help`, `wisp run --help`) (Serves: Next)
- A never-run session is a valid `--parent`, because `wisp new` without `-s` still writes `wisp.jsonl` and `wisp.run.json`, and `wisp ls --tree` then shows the run tree; that is why each task gets a `tasks/<id>/root/` session. (From: `wisp new --help`, `.tickets/ai-wpueub/ticket.md` finding 6) (Serves: Next)
- `wisp new --parent` appends the child id to the parent's `children` list with last-writer-wins, so the children list cannot hold task state; the ledger must. (From: `wisp/wisp` `link_child`, `.tickets/ai-wpueub/ticket.md` finding 6) (Serves: Next)
