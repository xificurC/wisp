## Goal

Give you commands that compare the four pushed commits with their rewritten counterparts, so the scrub is reviewable as a diff before the force-push.

**One sentence:** Both histories pair one-to-one by position, and `git range-diff` is the command that isolates exactly which commits the scrub changed.

**Four sentences:** `main` holds nine commits and `origin/main` holds the four published ones; the same commit subjects, authors, and dates line up by position. `git range-diff` compares each old patch with its new patch and prints `=` for identical and `!` for changed. Only the root commit and the `wisp-o2llma` commit report `!`; the middle two carry no scrub of their own. `git diff origin/main main~5` then shows the whole scrub as one 421-line diff, and that output equals the diff against the pre-scrub local tip byte for byte.

## The pairing

Run `git fetch origin` first, then read this map:

| pushed | rewritten | commit |
|---|---|---|
| `f8a3040` | `2cdbf68` | Import wisp, wispy, and tikit |
| `4616c61` | `99ef05e` | tikit: gate ticket ids and overwrites… |
| `db3dfdf` | `f251117` | wisp: serve one non-stream chat turn… |
| `e0d468f` | `f1f853a` | closed(wisp-o2llma): running wisp… |

`main~5` is `f1f853a`, the rewritten twin of the pushed tip. `main` carries four extra unpushed commits above it.

## 1. Cleanest per-commit comparison: `git range-diff`

```bash
git range-diff -s origin/main~3..origin/main main~8..main~5
```

Verified output:

```
1:  4616c61 = 1:  99ef05e tikit: gate ticket ids and overwrites...
2:  db3dfdf = 2:  f251117 wisp: serve one non-stream chat turn...
3:  e0d468f ! 3:  f1f853a closed(wisp-o2llma): running wisp...
```

Drop `-s` to see the patch of each changed commit. Add `--no-dual-color` for plain text.

The root pair escapes every range, because a range cannot hold a root commit. Compare the root pair on its own:

```bash
git range-diff -s f8a3040...2cdbf68
```

That prints one pair, `1: f8a3040 ! 1: 2cdbf68 Import wisp, wispy, and tikit`.

## 2. Whole-history map, all nine pairs

```bash
git range-diff -s refs/backup/pre-scrub~8..refs/backup/pre-scrub main~8..main
git range-diff -s f8a3040...2cdbf68
```

Pairs 4 through 8 report `=`, so the five unpushed commits kept their patches intact.

## 3. Per-commit snapshot stats

`range-diff` compares patches; this loop compares trees at each aligned point:

```bash
paste <(git rev-list --reverse origin/main) \
      <(git rev-list --reverse main | head -4) |
while read -r o n; do
  printf '%-9s -> %-9s  %s\n' "$o" "$n" "$(git log -1 --format=%s "$o")"
  git diff --stat "$o" "$n"
done
```

The counts grow because each `git diff` reports the accumulated scrub: 8 files at the root, then 20 files by the pushed tip.

## 4. The whole scrub as one diff

```bash
git diff --stat origin/main main~5
git diff origin/main main~5
```

That yields 20 files, 61 insertions, and 54 deletions. The same command against the local pre-scrub tip gives the identical 421 lines:

```bash
git diff refs/backup/pre-scrub main | cmp - <(git diff origin/main main~5) && echo same
```

Two cautions. `git diff origin/main main` mixes the four unpushed commits into the scrub, so use `main~5` for review. The `-` side of every hunk holds the old values by construction.

## 5. Viewing without re-leaking

The scrub removed the company gateway host and the deployment slugs, so a plain diff echoes both. Mask them on the removed lines only:

```bash
git diff origin/main main~5 |
sed -E '/^-/ s#https?://[^ `")]+#<URL>#g; /^-/ s/(deepseek|glm|claude|qwen)[A-Za-z0-9._-]*/<MODEL>/gi'
```

That leaves the new side readable as `https://company-litellm.example.com/...` and `DeepSeek V4.1 Flash`.
