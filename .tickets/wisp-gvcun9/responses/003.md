Goal: implement live tool streaming in `wisp/wisp` with the user's three decisions.

TLDR: tool-call arguments now stream from the producer as `wisp:tool_delta` markers (Option B), tool output streams through a new `Executor.run` head callback as `wisp:tool_output` markers capped at `maxKilobytes`, and the renderer prints the status line last.

**What changed in `wisp/wisp`**

- `sse_stream` calls the new `tool_deltas_of(chunk)` after `chunk_of` and writes one `data: {"wisp":"tool_delta","index":N,"id":...,"name":...,"arguments_delta":"..."}` line per provider-normalized fragment. All three dialects merge before the renderer sees a shape.
- `Executor.run` takes an optional `on_head` callback. `on_head` receives every byte chunk that enters the head and never the spill tail.
- `Tools._run_tool` decodes those chunks with an incremental UTF-8 decoder and injects `data: {"wisp":"tool_output","call_id":...,"content_delta":"..."}`.
- `Renderer.tool_delta` opens the fence on the first fragment and appends only new text decoded from the partial JSON (`decode_json_prefix`, `json_string_value_start`, `display_key_of`). A split escape waits for its tail; a split surrogate pair combines.
- `Renderer.tool_header` closes the drawn fence and writes the `[bash 5s 5kb]` tag line last. A call with no fragments (replayed record, non-stream turn) draws the same block in one step.
- `Renderer.tool_output` streams the head; `Renderer.tool_result` skips content it already streamed, prints the `wisp:tool` status line, then the SGR reset.

**Resulting human shape**

```
```
echo hi
```
[bash 5s 5kb]

hi
wisp:tool bash exit=0 ms=43
^[[0m
```

The tag trails because `timeoutSeconds` and `maxKilobytes` arrive only with the complete argument JSON. The status trails because output arrives first. The model wire is untouched: `tool_text_of` and the three dialect mappers still send the status first.

**Two invariants changed, per your decision**

- The human render no longer prints the exact model text order; only the order differs, not the field set.
- `md/design/tool-result-status.md` gains a 2026-11-17 section recording the new shape; the 2026-11-10 section still records the old one.
